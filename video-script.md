# Co-Desk — Demo video script (< 3 minutes)

Keep it tight. Record a screen capture with the deployed URL open in a
WebMCP-enabled browser (Chrome flag or ChatGPT in-app browser) plus voiceover.
Suggested total ~2:15.

## 0:00–0:20 — Hook (problem)
> "An AI assistant helping with a real web app used to have to click its way
> through your UI — slow, brittle, and impossible to verify.
> Co-Desk fixes that with WebMCP."

*(Show a support queue filling up.)*

## 0:20–0:45 — What it is
> "Co-Desk is a support desk built *for people and their agents together*.
> The site exposes its whole workflow as WebMCP tools — list, open, note, route,
> escalate, resolve."

*(Zoom to the header badge flipping to "WebMCP connected — agent tools registered".)*

## 0:45–1:15 — The human side
> "As a person I can work the queue normally — open a request, route a team,
> escalate, resolve — and it updates live."

*(Click to create a ticket and route one; point at the live activity feed.)*

## 1:15–1:55 — The agent side (the key moment)
> "Now I'll bring an agent in on the same queue."
> "Summarize the Co-Desk queue, then handle the password-reset ticket — add a
> note, route it to account, and show me before you resolve it."

*(Show the agent discovering tools and calling them; the queue and activity feed
update live on the same screen. Highlight each action appearing.)*

## 1:55–2:15 — Wrap-up
> "One shared queue. Two operators. The agent clears the routine backlog while I
> stay in the loop and own the judgment calls.
> That's what WebMCP makes possible — human and agent, working together."

*(Final full-screen shot of Co-Desk + a line "webmcp-gen was used to scaffold the
tool schemas." if relevant.)*

---
### Production notes
- Keep audio clear; speak slowly.
- Show the deployed URL in the browser address bar early so judges trust it is live.
- No copyrighted music; clean voiceover only.
